# 🍔 Swiggy Sales & Performance Dashboard (Excel)

An interactive Microsoft Excel business intelligence dashboard designed to analyze Swiggy's order metrics, revenue trends, customer ratings, and geographic performance across India.

---

## 📌 Project Overview
This project provides an end-to-end operational and sales analysis for food delivery orders on Swiggy[cite: 7]. By utilizing Excel Pivot Tables, formulas, dynamic charts, and slicers, the dashboard offers business stakeholders quick access to macro-level KPIs and category-level drill-downs[cite: 7].

---

## 🎛️ Interactive Features & Slicers
* **Navigation Panel:** Quick sheet navigation buttons linking to `DASHBOARD`, `ANALYSIS`, and `DATA`[cite: 7].
* **Months Slicer:** Filter all metrics by individual months (Jan to Sep)[cite: 7].
* **Category Slicer:** Slice data by food categories (e.g., *Desi Ghee Sweets*, *Chinese*, *Pasta*, *Roll*)[cite: 7].
* **Restaurant Slicer:** Deep-dive into specific vendor performances (e.g., *175 C*, *1944 The Hocco Kitchen*, *4 Seasons*)[cite: 7].
